# 项目需求文档

## 项目概述

**项目名称**：Klog
**项目形态**：PWA（渐进式 Web 应用），浏览器使用，可安装到桌面
**定位**：个人笔记整理工具，本地优先，导出/导入分享

## V1.0（当前版本 — 已完成）

| 功能 | 描述 |
|------|------|
| 文件夹无限嵌套 | 像文件系统一样创建多级目录 |
| 多图上传 | 拖拽/点击上传多张照片，支持 JPG/PNG |
| 图片拖拽排序 | 照片之间可拖拽换位 |
| 图片页码标注 | 每张照片左下角自动标序号 1, 2, 3... |
| 富文本摘录 | 加粗、高亮、Bullet List，对照片内容做总结 |
| 标签系统 | 输入+回车添加标签，可按标签筛选笔记 |
| 笔记排序 | 最近更新 / 最早更新 / A-Z |
| 笔记删除 | 确认后删除 |
| 文件夹选择 | 新建/编辑笔记时选择归属文件夹 |
| 全部笔记视图 | 平铺所有笔记，按标签筛选 |
| 本地存储 | IndexedDB，离线可用 |
| PWA 安装 | 可安装到桌面，离线使用 |

## V1.1（计划中）

### 1. 编辑 / 只读模式切换 ✅

- 笔记页顶部加一个切换开关
- **编辑模式**：与现状一致，可修改所有内容
- **只读模式**：
  - 标题和摘录渲染为不可编辑状态
  - 照片放大显示，适合翻阅复习
  - 所有编辑控件（加粗、高亮、删除、拖拽等）隐藏
- 适用场景：做笔记时用编辑模式，复习时切只读模式避免误改

### 2. 文件附件（PDF / Word）✅

- 笔记支持上传 PDF、Word 文件作为附件（不是转换）
- **智能处理规则**：
  - 文件超过一定大小（如 10MB）→ 自动作为附件存储，点击用浏览器内置阅读器打开
  - 文件较小（≤10MB）→ 用户可选择：
    - A：作为附件（保留原文件）
    - B：PDF 逐页转换成图片加入照片区（适合短文档）
    - C：Word 提取文字自动填入摘录区，图片加入照片区
- 附件以文件名+图标形式展示在照片区下方
- 附件不需要页码标注

### 3. 导出 / 导入笔记 ✅

- **导出**：
  - 可导出单条笔记、某个文件夹、或全部笔记
  - 生成一个 `.klog` 文件（JSON 格式，包含文件夹结构+笔记数据+照片）
- **导入**：
  - 拖拽/选择 `.klog` 文件
  - 自动还原文件夹结构、笔记、照片、标签
  - 如果 ID 冲突（同名文件夹/笔记），提示用户选择覆盖或跳过
- 分享流程：A 导出文件 → 发给 B → B 在自己电脑的 Klog 里导入 → B 看到完整网站界面和笔记内容

## 非功能需求

- **隐私**：所有数据默认存储在本地浏览器 IndexedDB，不上传任何服务器
- **离线**：PWA 模式，无网络环境下完整可用
- **性能**：导出/导入文件应支持 100+ 条笔记不卡顿
- **兼容性**：支持 Chrome 90+、Safari 15+、Edge 90+
